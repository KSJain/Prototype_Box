# Contributing

Thank you for your interest.

The KSJ ecosystem is built around clarity, reliability, and learning.

Please read the Engineering Standard before contributing.

---

## Philosophy

Small consistent improvements.

Simple APIs.

Readable code.

Thoughtful documentation.

Reliable examples.

---

## Pull Requests

Every contribution should:

□ Build successfully

□ Include an example

□ Update documentation

□ Update CHANGELOG if needed

□ Follow the Engineering Standard

---

The goal is not simply to add features.

The goal is to leave the project easier to understand than when you found it.
